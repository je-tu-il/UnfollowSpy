Qui vous suit
en retour ?

Comparez vos abonnés et vos abonnements Instagram. Vos fichiers restent sur cet appareil.

Importer vos listes

Les listes sont détectées automatiquement dans le dossier et ses sous-dossiers.

Ou choisissez les fichiers manuellement

Où trouver ces fichiers ?
  1. Ouvrez Vos informations et autorisations dans l’Espace Comptes. Sur mobile, ouvrez votre profil Instagram, appuyez sur le menu ☰, puis sur Espace Comptes.
  2. Choisissez Exporter vos informations (ou Télécharger vos informations), créez un export et sélectionnez votre profil Instagram.
  3. Choisissez l’export vers votre appareil. Dans les informations à inclure, sélectionnez Abonnés et abonnements. Réglez la période sur Depuis le début et choisissez JSON ou HTML.
  4. Lancez l’export. Quand Instagram vous avertit qu’il est prêt, revenez sur la même page pour télécharger le ZIP, puis décompressez-le.
  5. Cliquez sur Ouvrir le dossier Instagram et sélectionnez le dossier décompressé. En import manuel, cherchez le dossier followers_and_following et sélectionnez tous les fichiers followers_* ainsi que le fichier following dans leurs champs respectifs.
